# TechCheck AI

Русскоязычное приложение для предварительного сравнения ТЗ, предложения и паспорта одного низковольтного трёхфазного асинхронного электродвигателя.

## Быстрый запуск в Windows / VS Code

Для владельца без опыта программирования: [START_HERE_RU.txt](START_HERE_RU.txt). Для соревнования подготовлена независимая папка `D:\TechCheck_Competition_2026-10-23` и полный ZIP на D. В ней запустите **Start-Demo.cmd**; Node.js уже включён. Браузер откроется после проверки готовности сервера. При занятом порте выбирается следующий. Сохраните всё содержимое готовой папки; отдельный файл запуска не заменяет приложение.

Готовый казахский текст: [competition/Presentation-KK.html](competition/Presentation-KK.html) или [TXT](competition/Presentation-KK.txt). Резервные экраны без сервера: [competition/Offline-Demo.html](competition/Offline-Demo.html). Внешний ИИ и личные ключи в переносимую копию не включены.

На этом компьютере зависимости уже установлены и production-сборка создана: достаточно `npm.cmd run start` из папки проекта или двойного щелчка по `Start-TechCheck.cmd`. Если сервер уже запущен, просто откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Что реализовано

- Главная, обзор текущей сессии, новая проверка, три учебных примера, справка.
- Реальное чтение PDF и TXT UTF-8, вставка текста, выбор файла и drag-and-drop, замена, удаление, просмотр блоков/страниц.
- Редактируемые требования, единицы, точное сравнение, минимум, максимум, диапазон и ручная оценка. Ручное добавление восьми поддерживаемых параметров.
- Серверная валидация цитат, привязки к модели и единиц. Детерминированный модуль сравнения.
- Отчёт с фильтрами, цитатами и контекстом, JSON, печать/PDF через диалог браузера, режим показа и выход по Esc.
- Изменение входных данных делает старый отчёт неактуальным. Экспорт блокируется до повторного подтверждения и сравнения.
- Документы не сохраняются в localStorage. На сервере — временная память, не более 30 сессий на процесс, срок 30 минут с периодической очисткой. Кнопка «Очистить» удаляет активную серверную сессию и состояние интерфейса. Перезагрузка браузера сбрасывает интерфейс; оставшаяся серверная сессия удаляется по сроку.

## Демонстрация

Смотрите [DEMO_SCRIPT.md](DEMO_SCRIPT.md). Пример А даёт 3 совпадения, 2 расхождения и 1 пропуск; изменение частоты на 60 Гц — 4 / 1 / 1. Б даёт шесть совпадений. В даёт пять совпадений и конфликт частоты с двумя цитатами поставщика.

## Режимы и ограничения

**Учебный режим** использует встроенные документы и настоящий модуль правил. ИИ не вызывается.

**Шаблонное извлечение** — ограниченная грамматика русских и английских строк: `Модель: MOTOR`, `Мощность: 15 кВт`, `Частота: 50 Гц`, `Число фаз: 3`, `Монтаж: IM B3`, `Защита: IP55`, `Режим: S1`, `Напряжение: 380 В`. Поддерживаются формулировки учебного ТЗ и `Power`, `Frequency`, `Phases`, `Mounting`, `Protection`, `Duty`, `Voltage`, `Model`. Это не нейросеть и не универсальный парсер таблиц. Нераспознанные записи и несколько моделей требуют ручной проверки. До подтверждения просмотра текста отсутствие распознанного значения имеет статус NEEDS_REVIEW, а не NOT_STATED.

**ИИ-анализ** настроен на этом компьютере через OpenAI Responses API и `gpt-5-mini`. Ключ сохранён в игнорируемом `.env.local`. Реальный запрос 23 октября 2026 достиг OpenAI, но получил `429 credit_balance_exhausted` / `insufficient_quota`: требуется пополнение API-баланса. Успешный ответ модели пока не получен. Модель извлекает факты, а не выставляет статусы. Строгая Zod-схема запрещает дополнительные поля; сервер проверяет дословные цитаты, блоки, страницы, модель и поддерживаемую интерпретацию. Автоматический MATCH возможен только при подтверждении явной грамматикой. Более сложное извлечение направляется на ручную оценку.

PDF: до 5 МБ, 10 страниц на файл и 20 страниц в комплекте. До 120 000 символов на источник. OCR, DOCX, XLSX и изображения не поддерживаются. Повреждённый, зашифрованный, пустой или частично непрочитанный PDF выдаёт ошибку. Страницы — физические страницы PDF; для TXT используются номера блоков. Панель показывает извлечённый текст, а не исходную графическую страницу.

Сверка не определяет подлинность паспорта, состояние оборудования, взаимозаменяемость, безопасность или допуск к эксплуатации. Она не является инженерным согласованием.

## Серверная конфигурация ИИ

Настройки перечислены с пустыми значениями в `.env.example`. Для разработки используется игнорируемый `.env.local`, для размещения — секреты сервера. В браузер, Git и отчёт API-ключ не попадает. Реальная конфигурация выполняется владельцем отдельно, без передачи ключей через чат.

| Настройка | Назначение |
|---|---|
| `OPENAI_API_KEY` | Серверный ключ; по умолчанию отсутствует |
| `OPENAI_MODEL` | Поддерживаемая модель Responses API со Structured Outputs; без неявного значения по умолчанию |
| `TECHCHECK_AI_ENABLED` | Только `true` разрешает режим при наличии остальных настроек |
| `TECHCHECK_ACCESS_TOKEN` | Отдельный код закрытого доступа к платной обработке; это не API-ключ |
| `TECHCHECK_AI_MAX_CALLS` | Не более 20 запросов за жизнь процесса, по умолчанию 5 |

Каждый запрос ИИ требует кода доступа и согласия на отправку текста, имён и структуры документов. Код не записывается в браузерное хранилище. Ограничены размер входа, выход (6000 токенов), число запросов и параллелизм (1). Таймаут 45 секунд, автоматических повторов нет. Ошибки не заменяются учебными данными. Успешный отчёт содержит факт вызова, фактическую модель и response ID.

Лимит запросов хранится в памяти и сбрасывается при перезапуске; он не является денежным лимитом аккаунта. Для публичного размещения платной обработки нужны HTTPS, постоянные ограничения запросов/бюджета и инфраструктурная авторизация. До такой настройки оставляйте ИИ выключенным. Локальный сервер привязан к 127.0.0.1. Публичное размещение в рамках этой работы не выполнено.

Официальные источники: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [GPT-5 mini](https://developers.openai.com/api/docs/models/gpt-5-mini), [ошибки API](https://developers.openai.com/api/docs/guides/error-codes). Ошибки исчерпания баланса, лимита расходов, квоты и временного ограничения частоты обрабатываются раздельно.

### Как пользоваться подключённым ИИ

1. Пополните [API-баланс OpenAI](https://platform.openai.com/settings/organization/billing). Проверенный ответ `credit_balance_exhausted` означает отсутствие доступных предоплаченных средств; ожидание само по себе это не исправит.
2. Откройте приложение, загрузите документы или откройте учебный комплект и выберите **ИИ-анализ**.
3. Запустите `Copy-AI-Access-Code.cmd` в папке проекта. Он копирует только отдельный код доступа приложения; вставьте его в поле **Код закрытого доступа**. API-ключ не копируется и не выводится.
4. Подтвердите отправку документов, нажмите **Извлечь требования**, проверьте требования и выполните сравнение.

Для недорогих начальных экспериментов можно также рассмотреть `model: "gpt-6-luna"` ([официальная страница](https://developers.openai.com/api/docs/models/gpt-6-luna)). Сейчас оставлена настройка `gpt-5-mini`; смена модели не устраняет отсутствие баланса.

После пополнения доступна ручная браузерная проверка с одним реальным вызовом на синтетическом комплекте:

```powershell
$env:TECHCHECK_LIVE_TEST='1'
node --preserve-symlinks scripts/verify-live-ai.mjs
Remove-Item Env:TECHCHECK_LIVE_TEST
```

Она не входит в обычные тесты, не записывает трассу с кодом доступа и сохраняет отчёт только после успешного ответа. Обычные тесты не обращаются к OpenAI. Первый созданный ключ «Codex», который не удалось сохранить из временного каталога, остался в Platform; его можно удалить по более раннему времени создания. Приложение использует второй ключ. Временные файлы успешного сохранения удалены.

План первого коммерческого пилота — [PILOT_PLAN.md](PILOT_PLAN.md).

## Проверки

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
```

Браузерные тесты используют установленный Google Chrome через Playwright. Если Chrome отсутствует, установите его либо измените `channel` в `playwright.config.ts` на `msedge`, когда установлен Edge. Браузер не скачивается автоматически.

`npm.cmd run fixtures` повторно создаёт синтетические TXT и PDF-файлы для тестов. Тестовые PDF содержат английские записи и стандартный встроенный шрифт, не требуют системных шрифтов.

Фактические результаты запусков — в [VALIDATION.md](VALIDATION.md), браузерный HTML-отчёт после тестов — в `playwright-report/index.html`. В `test-results` сохраняются снимки основных экранов, печатный PDF и трассы неудачных тестов. Это только синтетические данные.

## Структура

- `src/app` — Next.js App Router, стили, API чтения/извлечения/сравнения.
- `src/components` — экраны, загрузка, редактор, отчёт и доказательства.
- `src/lib` — строгие схемы, фикстуры, нормализация, шаблоны, проверка доказательств, правила сравнения.
- `src/server` — PDF-reader, временные сессии, серверный адаптер, ограничение входа и обработка ошибок.
- `public/examples` — скачиваемые учебные документы.
- `tests` — проверки правил и реальный сценарий в браузере.

Стек: Next.js App Router, React, TypeScript, CSS, Lucide, Zod, pdf-parse. Совместимость PDF-reader с Node.js 24 проверяется загрузкой настоящего PDF. Точные установленные версии фиксируются в `package-lock.json`.
